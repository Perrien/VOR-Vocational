# Complete the Execution Protocol

Status: open
Filed: 2026-09-17

`Execution-Protocol.md` was installed with three of its four declaration blocks left as
`⟦FILL IN⟧`, because a project scaffolded before its first line of code cannot answer them honestly.
They share one trigger: the moment the project exists and has a stack, all of these become answerable
in a single sitting.

- [ ] **Paths** — the deliverable / source tree row, the only unfilled row in an otherwise complete
      block. The folder didn't exist at scaffold time.
- [ ] **Gates** — the ordered list of checks that run before any task is marked done, as real
      commands for this project. State which are conditional and on what.
- [ ] **Guardrails** — this project's hard constraints. What must never be edited, weakened, upgraded
      or touched to make progress.
- [ ] **Environment & toolchain** — anything about this machine or toolchain that changes how the
      agent works. Delete the block if there's nothing.
